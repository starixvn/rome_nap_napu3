\n
${txtDate}: the xpath value of textbox Date in calendar\n
\n
${strDate}: the chosen date value (YYYY-MM-DD) (eg, 2013-08-01) \n
\n
\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ or special value: Now (for current day), Now -1 day (for yesterday)\n
${tmplist}= get time year month day ${strDate}
${tmpYear}= Collections.Get From List ${tmplist} 0
${tmpMonth}= Collections.Get From List ${tmplist} 1
${tmpDay}= Collections.Get From List ${tmplist} 2
${tmpDay}= Convert To Integer ${tmpDay}
${tmpDay}= Convert To String ${tmpDay}
${tmpMonth}= Evaluate int (${tmpMonth}-1)
${tmpMonth}= Convert To String ${tmpMonth}

... ${tmpDay}
