Keywords
Edit LiveCasino Bet setting [Arguments] ${type} ${maxPT} ${comm}
... ${checkPartyBaccarat}
[Documentation] This action is used to edit Live Casino bet setting.Just use it when current frame is Edit Casino page\n
\ \ \n
\n
${type}: the account type (Super, Master, Agent or Member)\n
\n
\ \n
${maxPT}: the Soccer min bet value \n
\n
\n
${comm}: the comm value\n
\n
\n
${checkPartyBaccarat}: 0 or 1 to uncheck/check Party Baccarat bet limit\n
\n
${outputMsg}: the output value that get in web page after clicking on Submit button\n
# set xpath of control
${tmpComm} Set Variable If '${type}'=='Super' or '${type}'=='Member' //select[@class='pt comm' and (@id='Comm' or not(@h))]
... //select[@class='pt comm' and @c]
${tmpMaxPT} Set Variable If '${type}'=='Super' //select[@id='MaxPT']
... //select[@class='pt comm' and (@h or @mx)]
${tmpkw} Set Variable If '${checkPartyBaccarat}'=='0' Unselect Checkbox
... Select Checkbox
${tmprdPartyBaccarat050} Replace String ${ELCSrdPartyBaccarat} 1-100
... 0.5-50
${tmprdPartyBaccarat} Set Variable If '${checkPartyBaccarat}'=='0' ${tmprdPartyBaccarat050}
... ${ELCSrdPartyBaccarat}
# Set value
Select From List By Value ${tmpComm} ${comm}
Select From List By Value ${tmpMaxPT} ${maxPT}
Run Keyword If '${type}'=='Member' Click Element ${tmprdPartyBaccarat}
Run Keyword If '${type}'<> 'Member' ${tmpkw} ${ELCSchkPartyBaccarat}
Click Update ${ELCSlblUsername} ${ELCSbtnUpdate} ${cfAccountPrefix}
${outputMsg} Get Edit Msg ${ELCSdivMsg} ${cfTimeOut} * 3
Sleep 5s
[Return] ${outputMsg}
Get LiveCasino Bet setting [Arguments] ${type}
[Documentation] This action is used to get Live Casino bet setting.Just use it when current frame is Edit Casino page\n
\ \ \n
\n
${type}: the account type (Super, Master, Agent or Member)\n
\n
\n
${outputlist}: the output list contains maxPT, Comm and status of PartyBaccaract checkbox\n
# set xpath of control
${tmpComm} Set Variable If '${type}'=='Super' or '${type}'=='Member' //select[@class='pt comm' and (@id='Comm' or not(@h))]
... //select[@class='pt comm' and @c]
${tmpMaxPT} Set Variable If '${type}'=='Super' //select[@id='MaxPT']
... //select[@class='pt comm' and (@h or @mx)]
# Get value
${maxPT} Get Selected List Value ${tmpMaxPT}
${comm} Get Selected List Value ${tmpComm}
${outputlist} Create List ${maxPT} ${comm}
[Return] ${outputlist}
