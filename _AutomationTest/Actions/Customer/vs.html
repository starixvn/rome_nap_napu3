Edit Virtual Sport Bet Setting [Arguments] ${type} ${sport} ${min}
... ${max} ${maxPM} ${maxPT}
[Documentation] This action is used to edit Virtual sport bet setting.Just use it when current frame is Edit Virtual Sports page\n
\n
\n
${type}: the account type (Super, Master, Agent or Member)\n
\n
\n
${sport}: the sport name (Virtual Soccer/Virtual Tennis/Virtual Horse Racing)\n
\n
\n
${min}: the min bet value \n
\n
\n
${max}: the max bet value\n
\n
\n
${maxPM}: the max per match value \n
\n
\n
${outputMsg}: the output value that get in web page after clicking on Submit button\n
# set dictionary
${tmpDict}= Create Dictionary Super s4
Set To Dictionary ${tmpDict} Master m3
Set To Dictionary ${tmpDict} Agent a2
Set To Dictionary ${tmpDict} Member a1
Set To Dictionary ${tmpDict} Virtual Soccer 1201
Set To Dictionary ${tmpDict} Virtual Tennis 1220
Set To Dictionary ${tmpDict} Virtual Horse Racing 1231
Set To Dictionary ${tmpDict} Virtual Greyhounds 1231
Set To Dictionary ${tmpDict} Virtual Motor Racing 1231
Comment Define maxpt id control
${tmpSportID}= Get From Dictionary ${SporttypeDict} ${sport}
${tmpBettype}= Get From Dictionary ${tmpDict} ${sport}
${tmptype}= Get From Dictionary ${tmpDict} ${type}
Comment Define element
${tmpMin} Set Variable ${EVStxtVirtualSoccerMinBet}
${tmpMax}= Set Variable If '${type}'=='Super' ${EVStxtVirtualSoccerSuperMaxBet}
... ${EVStxtVirtualSoccerMaxBet}
${tmpMaxPM}= Set Variable If '${type}'=='Super' ${EVStxtVirtualSoccerSuperMaxPM}
... ${EVStxtVirtualSoccerMaxPM}
${tmpMin}= String.Replace String ${tmpMin} Virtual Soccer
... ${sport}
${tmpMax}= String.Replace String ${tmpMax} Virtual Soccer
... ${sport}
${tmpMaxPM}= String.Replace String ${tmpMaxPM} Virtual Soccer
... ${sport}
${tmpMaxPT}= Set Variable //select[@id='${tmptype}\$${tmpSportID}\$${tmpBettype}']
Comment Set new bet limit values
Input Text ${tmpMin} ${min}
Input Text ${tmpMax} ${max}
Input Text ${tmpMaxPM} ${maxPM}
Select From List By Value ${tmpMaxPT} ${maxPT}
Click Update ${EVSlblUsername} ${EVSbtnUpdate} ${cfAccountPrefix}
${outputMsg} = Get Edit Msg ${EVSdivMsg} ${cfTimeout}
Sleep 5s
[Return] ${outputmsg}
