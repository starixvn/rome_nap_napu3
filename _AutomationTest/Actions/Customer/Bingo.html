Get Bingo Bet Setting [Arguments] ${type}
[Documentation] This action is used to edit Bingo bet setting. Just use it when current frame is Edit Bingo page\n
\n
${type}: account type (Super, Master, Agent or Member)\n
\n
${outputlist}: the output list containing maxTransfer,maxPT, comm and incentive values\n
${tmpcboMaxPT}= Set Variable If '${type}'== 'Member' ${EBcboMaxPTMember}
... ${EBcboMaxPT}
${maxTransfer} Get Value ${EBtxtMaxTrasferCredit}
${maxPT} Get Selected List Label ${tmpcboMaxPT}
${comm} Get Selected List Label ${EBcboComm}
${outputlist} Create List ${maxTransfer} ${maxPT}
... ${comm}
${incentive}= Run Keyword Unless '${type}'== 'Super' Get Selected List Label
... ${EBcboIncentive}
Run Keyword if '${type}'== 'Master' or '${type}'== 'Agent' Append To List ${outputlist}
... ${incentive}
[Return] ${outputlist}
