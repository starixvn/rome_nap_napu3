\n
${type}: account type (Super, Master, Agent or Member)\n
\n
${maxTransfer}: the max transfer credit value\n
\n
${RnGMaxPT}: RNG max PT value\n
\n
${RnGcomm}: the RnG comm value\n
\n
\n
${MiniMaxPT}: Mini max PT value\n
\n
${outputMsg}: the output value that get in web page after clicking on Submit button
# Set control
${tmpPrefix}= Get Substring ${type} 0
... 1
${tmpRnGMaxPT}= Replace String ${ECScboRnGMaxPT} S
... ${tmpPrefix}
${tmpRnGComm}= Replace String ${ECScboRnGComm} S
... ${tmpPrefix}
${tmpMiniMaxPT}= Replace String ${ECScboMiniMaxPT} S
... ${tmpPrefix}
${tmpRnGMaxPT}= Set Variable If '${type}'=='Member' ${ECScboRnGMaxPTMember}
... ${tmpRnGMaxPT}
${tmpRnGComm}= Set Variable If '${type}'=='Member' ${ECScboRnGCommMember}
... ${tmpRnGComm}
${tmpMiniMaxPT}= Set Variable If '${type}'=='Member' ${ECScboMiniMaxPTMember}
... ${tmpMiniMaxPT}

Select Checkbox ${ECSchkRnGGroupSetting}
Select From List By Label ${tmpRnGMaxPT} ${RnGMaxPT}
Select From List By Label ${tmpRnGComm} ${RnGComm}
Select From List By Label ${tmpMiniMaxPT} ${MiniMaxPT}
Click Update ${ECSlblUsername} ${ECSbtnUpdate} ${cfAccountPrefix}
${outputMsg} Get Edit Msg ${ECSdivMsg} ${cfTimeout} * 3
Sleep 5s
[Return] ${outputMsg}
Get Casino Game type [Arguments] ${type} ${isCheck}=1
[Documentation] This action is used to check/uncheck all bet limit checkbox and return the list Casino game type and . Just use it when current frame is Edit Casino page\n
\n
\n
${type}: RnG Game or Mini Game\n
\n
\n
${isCheck}: 0/1 \ (0: means uncheck)
${tmpRowNo}= Get Element Attribute ${ECStblSetting}//td[text()='${type}']@rowspan
${tmpRowNo}= Convert To Integer ${tmpRowNo}
${tmpRow} Set Variable ${ECStblSetting}//td[text()='${type}']/parent::tr/following::tr[not(@id)]
${output} Create List
: FOR ${index} IN RANGE 1
... ${tmpRowNo}
${tmptr}= Set Variable ${tmpRow}[${index}]
${tmptd}= Set Variable ${tmptr}/td[1]
${cell1}= Get Text ${tmptd}
${tmptd}= Set Variable ${tmptr}/td[2]
${cell2}= Get Text ${tmptd}
Select Unselect All Casino game type ${tmptr}/td[2]/input ${isCheck}
Append To List ${output} ${cell1};${cell2}
[Return] ${output}

Run Keyword And Continue On Failure ${tmpKeyword} ${tmpControl}[${i}]
