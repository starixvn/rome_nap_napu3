Get Edit Msg [Arguments] ${control} ${timeout}
[Documentation] This action is used to get the returned message on web page after clicking on Submit button.\n
Just use it when the current frame is Edit page\n
\n
Arguments: \n
\n
\ \ ${control} : the control contains the message\n
\n
\ \ ${timeout}: the time value that action will try to perform\n
\n
\ \ \ \ \ ${outputMsg}: the output value\n
\n
\n
\n
1. Select the window \n
\n
2. Select main frame \ \n
\n
3. Select Edit frame \ \n
\n
4. Get err msg then compare the value to inputed value (${errMsg}) \ \n
\n
5. Repeat step 4 until the \ value is equal as inputed value or the timeout value exceeded \ \n
\n
: FOR ${index} IN RANGE 1
... ${timeout}
${outputMsg} = Run Keyword And Continue On Failure Get Text
... ${control}
${tmplen}= Get Length ${outputMsg}
Run Keyword If ${tmplen}> 0 Exit For Loop
sleep 1s
Comment ${tmpSubstr} = String.Get Substring ${outputMsg}
... 1 2
Comment ${tmpStatus} Set Variable If '${tmpSubstr}' == ''
... False True
Comment Run Keyword If ${tmpStatus} Exit For Loop
[Return] ${outputMsg}
