This function supports multiple finance transfer between users which are using different currencies and so called Multiple Cross-Currency Finance Transfer.

The key point of this function is to import an excel file with a pre-defined structure which contains number of transfers and the system will automatically mapping those transactions into database.

Steps to use this function are described as follow:
  1. Click on “Browse” button and cite to an excel file for importing its contents. The excel file has to follow a pre-defined structure mentioned above and not larger than 1MB in size. You can download an excel file’s template by clicking “Click here to download template” link.

  2. Click on “Open File” button to check the excel file’s contents. The contents will be divided into Failed Transactions and Valid Transactions. Only Valid Transactions are updated in database.

  3. Click on “Update Now!” button for mapping those Valid Transactions into database.
