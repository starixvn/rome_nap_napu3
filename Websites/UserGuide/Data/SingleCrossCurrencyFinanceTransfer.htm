This function supports single finance transfer between users which are using different currencies and so called Single Cross-Currency Finance Transfer.

Steps to use this function are described as follow:
  1. Input the name of user who makes the transfer into From User area. The system will display the currency currently used by that user (so called A) below his/her name and the exchange rate between A and RM (system’s base currency).

  2. Input the name of user who will receive the transfer into To User area. The system will similarly display the currency currently used by that user (so call B) below his/her name; the exchange rate between B and RM, the exchange rate between A and B (which is calculated by the system based on RM as an intermediate currency between A and B and so called System’s Exchange Rate) are also calculated and shown accordingly.

  3. Input the amount of transfer into From Amount area (this amount is in A currency).

  4. Input the amount that receiver will get into To Amount area (this amount is in B currency). Right after this step, the Transaction’s Exchange Rate will be displayed so that the user can check the different between System’s Exchange Rate and Transaction’s Exchange Rate. The Transaction’s Exchange Rate here is directly calculated based on the input values from From Amount and To Amount.

  5. Select a Forex account from the drop-down list. This Forex account that uses the system’s base currency will be considered as an intermediate account for transferring finance between users using different currencies.

  6. Write a short remark statement before making transfer.

  7. Click “Transfer” button for transferring and you can see the transferring’s result.
